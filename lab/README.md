# 实验室安全与设备管理

一个独立的小页面，用于课题组每晚的设备使用备案、夜间安全检查（含拍照留证）和月底检查统计。

页面地址：**https://zju-iced-data.github.io/lab/**

## 流程

| 时间 | 谁 | 做什么 |
| --- | --- | --- |
| 每晚（建议 21:00 后） | 每个今晚要用设备的人 | 「① 今晚备案」填：姓名、设备、时长、反应内容、危险源分类 |
| 每晚（建议 21:30 后） | 最后一个离开实验室的人 | 「② 夜间检查」逐项确认水/电/气/设备，对每台备案设备拍照，署名提交 |
| 月底 | 管理员 | 「③ 记录与统计」按检查次数统计，可导出 CSV |

**提交不受时间限制**：21:00 / 21:30 只是推荐时段，任何时间都能填写和提交。
记录里的日期与时间按**提交那一刻自动记录**；预计结束时间 = 提交时刻 + 使用时长，跨过午夜标注「（次日）」。

## 数据存在哪

数据放在**独立的数据仓库** `ZJU-ICED-DATA/lab-data`（与主站仓库分离，令牌泄露也不会影响网站源码）：

```
records.json          所有备案与检查记录
options.json          成员 / 设备 / 时长选项
photos/<id>.jpg       检查照片（前端压到约 100 KB/张）
```

- **读取**：https://zju-iced-data.github.io/lab-data/records.json
  与页面同域名，**不需要代理**，任何网络都能直接看到所有人的记录。
- **写入**：浏览器直接用 GitHub 令牌提交到 `lab-data` 仓库，**不经过 Cloudflare**。

## 写入令牌（组员各自配置一次）

读取不需要令牌；**只有提交需要**。两种配置方式：

1. 打开页面 → 右上角「⚙ 设置」→ 粘贴令牌 → 保存
2. 或者直接打开带令牌的链接（配置后会自动从地址栏移除）：

   ```
   https://zju-iced-data.github.io/lab/?token=<令牌>
   ```

令牌要求：Fine-grained PAT，仅勾选 `lab-data` 仓库，权限 **Contents: Read and write**。

没填令牌时，提交会退回 Cloudflare Worker（`workers.dev` 在国内常被阻断，需要代理）。

## 部署 / 维护

### 页面

`lab/` 目录随主站仓库由 GitHub Pages 发布，改完推送约 1 分钟生效。
页面右下角有版本号，可据此确认是否为新版。

### 数据仓库 Pages

`lab-data` 仓库同样开启了 Pages（main 分支 / 根目录），提供 `records.json` 等静态文件。

### 修改时间提示

编辑 `lab/index.html` 顶部的 `RULE`（仅用于提示文案，不限制提交）：

```js
var RULE = { usageOpen: 21 * 60, checkOpen: 21 * 60 + 30, closeAt: 23 * 60 + 59 };
```

### 照片体积

前端把照片压到最长边 1000 px、JPEG 质量 0.6（约 80–150 KB/张，每台设备最多 4 张）。
按每晚 3 张估算，一个月约 10 MB；仓库变大后可以把历史月份照片归档。

## 安全说明

- 页面和数据仓库都是公开的，**任何人知道网址都能读取记录**。
- 写入令牌对 `lab-data` 有写权限，组内共享意味着任何人都能改记录；令牌不会写进网页源码。
- 照片存在公开仓库，请勿拍摄涉及个人隐私的画面。
