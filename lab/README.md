# 实验室安全与设备管理

一个独立的小页面，用于课题组每晚的设备使用备案、夜间安全检查（含拍照留证）和月底检查统计。

页面地址：**https://zju-iced-data.github.io/lab/**

## 流程

| 时间 | 谁 | 做什么 |
| --- | --- | --- |
| 每晚（建议 21:00 后） | 每个今晚要用设备的人 | 「① 今晚备案」填：姓名、设备、时长、反应内容、危险源分类 |
| 每晚（建议 21:30 后） | 最后一个离开实验室的人 | 「② 夜间检查」逐项确认水/电/气/设备，对每台备案设备拍照，署名提交 |
| 月底 | 管理员 | 「③ 记录与统计」按检查次数统计，可导出 CSV |

**提交不受时间限制**：21:00 / 21:30 只是推荐时段，任何时间都能提交。
表单里的「日期」「提交时间 / 离开时间」默认取当前时间，**可以手动改成任意时刻**，用于补录。
预计结束时间 = 所选时间 + 使用时长，跨过午夜会标注「（次日）」。

## 数据存在哪

两条路径，页面自动选择：

1. **本地模式（默认）**：数据只存在当前浏览器（localStorage）。适合单台设备试用，换手机看不到别人的记录。
2. **云端模式**：在「⚙ 设置」里填接口地址 + 实验室代码后，全组共享同一份数据。

云端数据通过 Cloudflare Worker（`worker.js`）写入本仓库：

```
lab/data/records.json       所有备案与检查记录
lab/data/photos/<id>.jpg    检查照片（前端已压缩到约 100 KB/张）
```

这样不需要额外数据库，也不会有第三方账号成本。

## 部署 / 维护

### 页面上线

`lab/` 目录随仓库一起由 GitHub Pages 发布，改完 `git push` 约 1 分钟生效。

### Worker（云端模式）

已经部署为 `lab-api`，地址：

```
https://lab-api.1014166708.workers.dev
```

页面里这个地址已经是**默认值**，组员只需要在「⚙ 设置」里填一次实验室代码即可（代码保存在各自浏览器）。

实验室代码当前为 `ICED-LAB-2026`（请自行修改后重新部署）。

-worker 的 Secret：`GITHUB_TOKEN`（有 repo 写权限）、`LAB_CODE`
- 普通变量：`REPO`、`BRANCH`、`ALLOWED_ORIGIN`

> ⚠️ `*.workers.dev` 在国内部分网络下会被 DNS 污染/阻断。如果组员打不开，
> 可以在 Cloudflare 给 Worker 绑定一个自己的域名，或临时用「本地模式」。
> 页面在连不上云端时会报错并提示，不会丢数据（提交前不会清空表单）。

### 修改时间规则

编辑 `lab/index.html` 顶部的 `RULE`：

```js
var RULE = { usageOpen: 21 * 60, checkOpen: 21 * 60 + 30, closeAt: 23 * 60 + 59 };
```

### 照片体积

前端会把照片压到最长边 1000 px、JPEG 质量 0.6，单张约 80–150 KB，每台设备最多 4 张。
按每晚 3 张估算，一个月约 10 MB。仓库变大后可以把历史月份的照片目录移到单独仓库。

## 安全说明

- 页面本身是公开的（GitHub Pages），**记录内容需要实验室代码才能读写**。
- 照片存在公开仓库里，请勿拍摄涉及个人隐私的画面。
- 如果以后要更严格，建议换成 Cloudflare D1/KV + 访问令牌，或部署到校园内网。
